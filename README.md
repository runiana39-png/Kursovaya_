# MigrationKit — учебный план адаптации разработчика к новой IDE

Практический проект курсовой «Проблемы и стратегии адаптации разработчика при смене инструментальной среды».

Система формирует прозрачный контрольный список перехода, рассчитывает **условную взвешенную готовность** и показывает оставшиеся действия. Веса назначены автором для демонстрации и **не являются экспериментальной оценкой продуктивности**.

## Запуск

Требуется Python 3.10+. Без сторонних библиотек.

```bash
python -m migrationkit.cli examples/progress.json
python -m unittest discover -s tests -v
```

Для сохранения отчёта:

```bash
python -m migrationkit.cli examples/progress.json --output report.json
```

## Что проверяется

Резервное копирование настроек, перенос расширений и клавиш, запуск проекта, зависимости, форматирование, отладка, тесты, Git и документация. Для каждой категории предусмотрена отдельная запись.

## Ограничения

Инструмент не анализирует реальные IDE, не переносит настройки автоматически, не собирает данные о разработчиках и не измеряет производительность. Итоговая доля — исключительно показатель выполнения собственного списка перехода. Репозиторий можно опубликовать после согласования адреса с владельцем.
