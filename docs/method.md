# Методика сравнения

1. Зафиксировать исходную среду и сценарии выполнения задач.
2. Сделать резервную копию настроек и отметить 10 контрольных действий.
3. Открыть проект в новой IDE, установить интерпретатор, прогнать тесты и отладку.
4. Для каждого действия отметить `done` как true или false.
5. Получить отчёт через CLI и проверить незавершённые шаги.

Оценка готовности не является оценкой времени обучения или UX. Для измерения скорости нужен отдельный эксперимент с людьми, одинаковыми задачами и контрольными условиями.
